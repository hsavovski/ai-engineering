## Why this matters

Every agent, from Claude Code to a customer-support bot, is the same small loop around tool calls. Writing it yourself removes the magic and gives you the project you'll grow through the rest of the book.

**Learning goals**

- Implement the agent loop with no framework
- Handle stop conditions, errors and max turns
- Observe how local and paid models differ in the loop
