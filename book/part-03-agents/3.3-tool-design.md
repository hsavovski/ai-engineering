## Why this matters

An agent is only as good as its tools, and tools for models are designed differently from APIs for programmers. Good tool design often matters more than the model choice.

**Learning goals**

- Design tool names, descriptions, inputs and outputs for a model
- Return errors and results that help the model recover
- Evaluate tools by watching the agent use them
