# Progress

Your study progress. Agents don't write here; what they build is logged in `BUILD-LOG.md`. Run `npm run progress` after merging chapter branches.

## How to track

- Click the status badge at the top of a chapter in the book as you go: `Not started` → `Reading` → `Practiced` → `Understood`. It's saved in your browser (localStorage), per reader, so it doesn't follow you across browsers or devices.
- Run `npm run progress` to regenerate the table below of which chapters are written.
- When you finish a study session, add a dated line to "My log": what you read or tried, and what's still fuzzy.

The old 7-section roadmap (run a local model, API, tiny agent, harnesses, evals, hybrid setup, deeper topics) is absorbed into the book outline in the spec. It is still in git history (commit `c99fe32`).
