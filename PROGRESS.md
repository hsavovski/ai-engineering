## How to track

- Set the `status` in a chapter's frontmatter as you go: `not-started` → `reading` → `practiced` → `understood`.
- Run `npm run progress` to regenerate the table below. Stubs (chapters not written yet) have no status to track.
- When you finish a study session, add a dated line to "My log": what you read or tried, and what's still fuzzy.
